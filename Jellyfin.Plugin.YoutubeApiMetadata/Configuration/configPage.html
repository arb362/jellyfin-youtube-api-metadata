YouTube API Metadata

Fetches metadata (title, description, thumbnails, channel info...) from the official YouTube Data API v3, instead of relying on yt-dlp.

Create a key in the Google Cloud Console with the YouTube Data API v3 enabled.
How long a cached API response is reused before being refreshed.

Lookups without IDs

When a series folder has no [channelId] in its name, search YouTube for the folder name (a handle like @rickastley is resolved exactly, 1 quota unit; any other name is a search, 100 quota units). Paid once per folder: the result is cached and stored on the item.
When a video file has no [videoId] in its name, search its channel for the file's title (100 quota units, once per file). Only an exact title match, or the top hit uploaded on the date in the file name, is accepted.
